# BOMBAA — fichiers de marque

- `bombaa-logo-black.svg/png` : logo horizontal noir, fond transparent.
- `bombaa-logo-white.svg/png` : logo horizontal blanc, fond transparent (à placer sur fond sombre).
- `bombaa-icon-black.svg/png` : symbole seul noir, fond transparent.
- `bombaa-icon-white.svg/png` : symbole seul blanc, fond transparent.
- `bombaa-app-icon.svg/png` : icône carrée blanche sur fond noir.
- `bombaa-favicon.svg`, `bombaa-favicon-512.png`, `favicon-32.png`, `favicon-16.png` : favicon.

Le SVG est le format vectoriel à privilégier pour le Web. Les PNG sont des exports raster.
La typographie du mot-symbole utilise Montserrat en priorité avec Arial comme solution de repli.
Pour un rendu identique sur tous les systèmes, installer/charger Montserrat dans le projet.
